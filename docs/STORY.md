# STORY

## シリーズの前提

近未来、行政・民間・警察のデータを横断する統合捜査局「AID」が設立された。主人公は、現場に出ないデータ統合分析官。未解決事件群には共通して、記録から意図的に削られた値 `NULL` が残されている。

各章は独立した事件として解決できるが、削除操作の署名、存在しない管理者ID、午前2時17分の同期障害が少しずつ一本の陰謀へつながる。

## CASE 001：存在しない404号室

### フック

2026年10月14日23時31分、HOTEL ARGOSの従業員が404号室で男性の遺体を発見した。通報を受けた警察がホテルの管理画面を確認すると、404号室は部屋マスタに存在しなかった。

### 主要人物

| 人物 | 表向きの立場 | 隠していること |
| --- | --- | --- |
| 神代誠司 | ホテル支配人 | 404号室への特別権限を持つ |
| 佐伯美咲 | 清掃責任者 | 10年前から404号室を清掃している |
| 加賀美透 | 405号室の宿泊客 | 被害者と同じ会社に在籍していた |
| 雨宮蓮 | 施設管理技師 | 4階の電力系統が図面と違うと知っている |
| 身元不明男性 | 被害者 | 10年前に死亡扱いになった内部監査人 |

### 真相の核

404号室は、ホテルの通常運用から隠された「監査保全室」だった。過去の事件記録をオフライン保存するため、客室マスタから削除されている。被害者は10年前に死亡を偽装され、保全室の記録を回収するため戻った。

事件当夜、支配人は削除権限を悪用してアクセスログを改変した。しかし改変対象外だった施設DB、ルームサービス端末の一時キャッシュ、清掃員の端末同期履歴には404号室が残った。

CASE 001で判明するのは実行犯と偽装方法まで。なぜ被害者が10年前に消されたのか、背後の `NULL` 管理者が誰なのかは後続章へ残す。

## M07の追加設定

M07追加設定（ユーザー承認済み）：神代誠司は自身が関与した無許可の記録廃棄を隠すため、当夜の監査資料回収を妨害した。本人認証付きの特別解錠資格で404区画へ入り、22:46に通常アクセスログの入室履歴を削除した。捜査側の鑑定による死亡推定時間帯は22:30〜22:40。身体的な殺害手段の詳細は評価対象にせず、方法欄では侵入・偽装方法を扱う。

追加資料には翌朝の鑑定・本人照合結果を含む。既存のカメラの外見タグだけでは人物を特定しない。10年前の事件の全容とNULL管理者の正体は後続章に残す。
